FONTS

Body text:    Sukhumvit Set (Medium, weight 500)
Display text: Broadsheet

Neither is available from Google Fonts, so they can't be loaded from the web automatically.

- Sukhumvit Set ships with macOS / iOS, so it is picked up automatically on Apple devices.
  For everyone else, add a licensed copy here named:  SukhumvitSet-Medium.woff2  (or .ttf)
- Broadsheet: add your licensed font file here named:  Broadsheet.woff2  (or .otf / .ttf)

The @font-face rules are at the top of style.css. Until the files are added, visitors on
non-Apple devices see a fallback (Helvetica/Arial for body, Georgia for display).
